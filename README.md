# Что дорожает быстрее?

Мини-сервис визуального анализа еженедельных индексов потребительских цен Росстата.

Проект сравнивает 6 повседневных категорий и автоматически показывает:
- лидера роста;
- самое сильное снижение;
- самую стабильную категорию;
- рейтинг динамики;
- краткий аналитический вывод;
- PNG-карточку 1080×1350 для соцсетей.

## Категории

- бензин АИ-95;
- яйца;
- хлеб из пшеничной муки;
- пастеризованное молоко;
- картофель;
- проезд в городском автобусе.

## Источник

Только официальный источник: Росстат  
https://rosstat.gov.ru/statistics/price

Используются **индексы потребительских цен в % к предыдущей дате регистрации**, а не абсолютные цены в рублях.

## Периоды

### 7 дней
Последний опубликованный индекс к предыдущей дате регистрации.

### 30 дней
В интерфейсе «30 дней» означает последние **4 недельных интервала (28 дней)**, поскольку исходные данные Росстата публикуются еженедельно.

Накопленное изменение считается через перемножение индексов:

```text
change = (index1/100 × index2/100 × index3/100 × index4/100 − 1) × 100
```

Проценты по неделям **не складываются**.

## Как запустить

Из-за загрузки JSON через `fetch()` проект нужно открывать через HTTP-сервер.

```bash
python -m http.server 8000
```

Затем открыть:

```text
http://localhost:8000
```

Или опубликовать репозиторий через GitHub Pages.

## Как обновлять данные

1. Скачать свежий XLSX Росстата.
2. Поместить его, например, в `source/nedel_Ipc.xlsx`.
3. Установить зависимости:

```bash
pip install -r requirements.txt
```

4. Выполнить:

```bash
python scripts/parse_rosstat.py source/nedel_Ipc.xlsx data/prices.json
```

5. Проверить сайт и закоммитить обновлённый `prices.json`.

## PNG

Кнопка «Скачать анализ в PNG» генерирует отдельную карточку размером 1080×1350, а не скриншот интерфейса.

## Методологическое ограничение

Проект — визуальный аналитический сервис, а не официальный индекс стоимости жизни. Категории имеют разные единицы измерения, поэтому их изменения сравниваются **по относительной динамике**, а не складываются в «потребительскую корзину».
